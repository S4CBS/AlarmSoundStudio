# AlarmSoundStudio

**Свои звуки будильника для системного приложения Windows «Часы» (Clock).**
Простое десктопное приложение: выбираете любой аудиофайл (mp3, m4a, ogg, flac…) — он автоматически конвертируется в WAV и становится звуком будильника «Часов». Без прав администратора, без изменения файлов системы.

*EN: Set any audio file (mp3, m4a, ogg, flac…) as the alarm sound of the built-in Windows Clock app. Converts to PCM WAV via Media Foundation and redirects the system alarm sound events. No admin rights required. Windows 10/11.*

---

## Как это работает

Будильник «Часов» не играет звук сам — он поднимает системные события Windows
`Notification.Looping.Alarm` / `Notification.Looping.Alarm2…10`, а ОС проигрывает
wav-файл, назначенный на событие в реестре:

```
HKCU\AppEvents\Schemes\Apps\.Default\Notification.Looping.AlarmN\.Current
```

AlarmSoundStudio:

1. **автоматически обнаруживает** все события будильника в вашей системе
   (сканирует реестр — количество слотов и их дефолты не зашиты в программу);
2. конвертирует выбранный аудиофайл в **PCM WAV (48 кГц / 16 бит)** через
   Media Foundation (системный конвертер, без ffmpeg);
3. перенаправляет выбранные события на полученный WAV (только ветка `HKCU`,
   текущий пользователь);
4. «Часы» (и таймеры) начинают проигрывать ваш файл сразу, перезапуск не нужен.

**Сброс** удаляет пользовательское значение из реестра — система возвращается
к собственным стандартным звукам, какие бы они ни были на данной машине.

## Возможности

- **Оверлей поверх окна «Часов»** (в стиле игровых читов): полупрозрачная панель всегда поверх окна «Часов», следует за ним, переключается по **Ctrl+Alt+S**; в ней — выбор файла, назначение на слот и кнопка ▶ у каждого слота
- **Выбор языка программы**: Русский / English (запоминается)
- Звуки хранятся в LocalState пакета «Часов» (гарантированно читается приложением) + зеркальная копия в %APPDATA% с ACL для AppContainer
- Поддержка повторного применения мода (уже вшитые имена распознаются и пропускаются)
- Тёмный WPF-интерфейс, нативный exe (~30 КБ), ничего не устанавливает
- Форматы: всё, что умеет Media Foundation — mp3, wma, m4a/aac, flac, mp4, wav; ogg/opus — если в системе есть кодек
- Назначение на все слоты сразу или на отдельный
- Прослушивание любого слота прямо из приложения
- **«Имя звука в «Часах»…»** — мод пакета: переопределяет «Часы» копией, в которой выбранный слот называется вашим именем (видно в списке звуков «Часов»); данные будильников сохраняются, есть кнопка «Вернуть оригинал»; включённый режим разработчика обязателен (1 UAC-запрос)
- Автосоздание ярлыка в меню «Пуск» после первого применения
- Полный сброс одним кликом
- Права администратора не нужны (кроме мода имён — 1 UAC)

## Как работает мод имён

Windows защищает файлы установленных пакетов на уровне ядра (даже с захваченным
владением запись в `WindowsApps` запрещена). Обход: пакет копируется, копия
патчится (имена звуков в `resources.pri`), **оригинал снимается с регистрации**
(`Remove-AppxPackage -AllUsers` + deprovision), а копия регистрируется с той же
identity (`Add-AppxPackage -Register`, loose-режим под Developer Mode не требует
подписи Microsoft). Так как family не меняется, данные будильников сохраняются.
Оригинал возвращается кнопкой «Вернуть оригинал» (эталонная копия пакета хранится
рядом). Обновление «Часов» из Microsoft Store заменит модификацию оригиналом —
просто запустите мод заново.

## Требования

- Windows 10 или Windows 11 (x64/x86)
- .NET Framework 4.7.2+ (предустановлен в актуальных Win10/11)
- Приложение «Часы» (предустановлено)

## Сборка

Системным компилятором .NET Framework — без установки SDK/Visual Studio:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Результат: `build\AlarmSoundStudio.exe`. Рядом с exe должна лежать папка
`tools\` (движок конвертации) — можно запускать прямо из репозитория.

## Использование

1. Запустите `AlarmSoundStudio.exe` (или из меню «Пуск» после первого применения).
2. «Добавить звук…» → выберите файл.
3. Выберите «На все слоты» или конкретный слот → «Применить».
4. Готово — будильник «Часов» теперь играет ваш файл.

Консольный вариант работы с реестром — см. описание событий выше; вся логика
сводится к одному значению `HKCU\...\Notification.Looping.AlarmN\.Current`.

## Ограничения (честно)

- **Кнопку внутрь «Часов» добавить нельзя**: это защищённый UWP/MSIX-пакет
  Microsoft без плагинной системы; содержимое пакета защищено на уровне ядра
  (проверено: смена ACL и владельца не даёт писать в файлы пакета).
- Названия слотов в списке «Часов» остаются стандартными — переназначается
  сам звук, а не подпись.
- Слоты общие: эти же события используют таймеры «Часов» и будильники других
  приложений, которые опираются на `ms-winsoundevent:Notification.Looping.Alarm*`.
- WAV на выходе всегда PCM 48 кГц/16 бит — самый совместимый формат для
  системного проигрывателя уведомлений.

## Удаление / откат

- В приложении: «Сбросить всё» — удаляет пользовательские значения `HKCU`,
  система возвращается к стандартным звукам.
- Полностью: удалите папку приложения и значение
  `HKCU\...\Notification.Looping.AlarmN\.Current` (или ключ `.Current` целиком).
